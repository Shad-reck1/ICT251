About Me

My name is Shadreck Mwami and I am a second-year student with a strong interest in technology and how websites are built. I chose Introduction to Web Technologies because I want to understand the full process of turning an idea into a working, attractive web page that real people can use. I enjoy learning by doing, so I spend time practising HTML and CSS in Visual Studio Code and testing my pages with Live Server. My goal is to become confident enough to build complete, responsive websites on my own and to keep improving my skills every single week.
